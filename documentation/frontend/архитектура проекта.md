
### 📁 Архитектура Android-приложения (MVVM + Clean Code)

В Android Studio у тебя будет один модуль `app`. Внутри папки `java/com/example/realmatch` создай следующую структуру:

```text
app/
├── data/                  # Слой данных (Сеть + Локальное хранилище)
│   ├── api/               # Retrofit интерфейсы
│   │   ├── AuthApi.kt
│   │   ├── UserApi.kt
│   │   └── ChatApi.kt
│   ├── models/            # DTO (Data Transfer Objects) - то, что приходит с бэкенда
│   │   ├── AuthResponse.kt
│   │   ├── UserDto.kt
│   │   └── ...
│   ├── repository/        # Репозитории (связывают API и ViewModel)
│   │   ├── AuthRepository.kt
│   │   ├── UserRepository.kt
│   │   └── ...
│   └── local/             # Хранение JWT-токена (EncryptedSharedPreferences)
│       └── TokenManager.kt
│
├── ui/                    # Слой представления (Экраны)
│   ├── auth/              # Экраны логина
│   │   ├── WelcomeScreen.kt
│   │   ├── EsiaLoginScreen.kt
│   │   └── AuthViewModel.kt
│   ├── feed/              # Экран ленты (свайпы)
│   │   ├── FeedScreen.kt
│   │   └── FeedViewModel.kt
│   ├── chats/             # Список чатов и сам чат
│   │   ├── ChatListScreen.kt
│   │   ├── ChatScreen.kt
│   │   └── ChatViewModel.kt
│   ├── profile/           # Профиль пользователя
│   │   └── ProfileScreen.kt
│   └── navigation/        # Навигация между экранами
│       └── AppNavigation.kt
│
├── utils/                 # Утилиты (константы, обработка ошибок)
│   └── ...
│
└── MainActivity.kt        # Точка входа
```
