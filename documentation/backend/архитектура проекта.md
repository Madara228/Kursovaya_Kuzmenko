 структура  проекта:

```text
backend/
├── app/
│   ├── __init__.py
│   ├── main.py                 # Точка входа (FastAPI app, CORS, статика)
│   ├── config.py               # Настройки (SECRET_KEY, DB_URL из .env)
│   ├── database.py             # Engine, SessionLocal, get_db
│   │
│   ├── models/                 # Слой данных (SQLAlchemy)
│   │   ├── __init__.py
│   │   ├── user.py
│   │   ├── contact.py
│   │   ├── message.py
│   │   ├── partner.py
│   │   └── promocode.py
│   │
│   ├── schemas/                # Слой валидации (Pydantic)
│   │   ├── __init__.py
│   │   ├── user.py
│   │   ├── contact.py
│   │   └── ...
│   │
│   ├── api/                    # Слой роутинга (Эндпоинты)
│   │   ├── __init__.py
│   │   ├── deps.py             # Зависимости (get_current_user)
│   │   └── routes/
│   │       ├── auth.py
│   │       ├── users.py
│   │       ├── contacts.py
│   │       ├── chats.py
│   │       ├── partners.py
│   │       └── invites.py
│   │
│   ├── services/               # Слой бизнес-логики (Сервисы)
│   │   ├── __init__.py
│   │   ├── auth_service.py
│   │   ├── user_service.py
│   │   ├── contact_service.py
│   │   ├── chat_service.py
│   │   ├── invite_service.py
│   │   └── partner_service.py
│   │
│   └── core/                   # Ядро (Утилиты, безопасность)
│       ├── security.py         # JWT, хеширование
│       └── exceptions.py       # Кастомные исключения
│
├── media/                      # Загруженные файлы
